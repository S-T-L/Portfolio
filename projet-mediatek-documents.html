Mediatek DocumentsApplication C# reliée à une API PHP

Application desktop de gestion documentaire pour MediaTek86, appuyée sur une API REST en PHP et une base MySQL.

Atelier pro
C#PHPMySQL
Contexte

Moderniser la gestion documentaire.

MediaTek86 souhaitait moderniser son système de gestion documentaire. La solution repose sur une application desktop en C#, appuyée sur une API REST en PHP et une base de données MySQL. Le système gère des documents variés — livres, DVD, CD, revues — et permet leur consultation ainsi que la gestion des emprunts.

Missions

Ce que j'ai développé.

  • Ajout d'onglets pour la gestion des commandes de livres, DVD et revues.
  • Mise en place de l'authentification avec gestion des droits par rôle.
  • Correction de failles de sécurité et mise en place de la journalisation (logs).
  • Tests unitaires (package Model) et tests fonctionnels via Postman.
  • Déploiement de l'API et création d'un installateur pour l'application C#.
  • Gestion des sauvegardes de données.
